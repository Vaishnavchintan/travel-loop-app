# Traveloop

Traveloop is a multi-city travel planning platform built for the Odoo Hackathon.

## Features

- Travel dashboard
- Multi-trip management
- Budget tracking
- Itinerary planning
- Mock API integration
- Responsive travel UI

## Tech Stack

Frontend:
- React
- Vite

Backend:
- Node.js
- Express

Database:
- MySQL (planned)

## Run Frontend

```bash
cd client
npm install
npm run dev
